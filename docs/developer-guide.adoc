=== Common Development Tasks

==== Setting Up Development Environment

[source,bash]
----
# Clone the repository
git clone https://github.com/CategoricalData/hydra
cd hydra

# Install all build dependencies
pixi install

# Validate the setup
pixi run validate

# Setup specific environments
pixi run -e haskell haskell-setup  # Complete Haskell development
pixi install -e java              # Java development environment
pixi install -e python            # Python development environment
pixi install -e scala             # Scala development environment

# Build all components
pixi run build-all
----

=== Complete Pixi Tasks Reference

This appendix provides a comprehensive reference to all available pixi tasks for Hydra development.

==== General Build and Setup Tasks

[source,bash]
----
# Core build tasks
pixi run build-all          # Build all components
pixi run build-java         # Build Java components
pixi run build-python       # Build Python components
pixi run build-scala        # Build Scala components
pixi run build-haskell      # Build Haskell components
pixi run build-ext          # Build extensions
pixi run clean              # Clean build artifacts
pixi run validate           # Validate setup
----

==== Java Development Tasks

[source,bash]
----
# Java environment tasks

pixi run -e java gradle-clean     # Clean Java build artifacts
----

----

[source,bash]

----

==== Haskell Development Tasks

===== Setup and Build
[source,bash]
----
pixi run -e haskell haskell-setup      # Complete setup
pixi run -e haskell haskell-setup-all  # Setup all packages
pixi run -e haskell stack-setup        # Stack setup
pixi run -e haskell stack-build        # Build all packages
pixi run -e haskell haskell-build-all  # Build all Haskell packages
pixi run -e haskell hydra-build        # Build core package
----

===== Testing
[source,bash]
----
pixi run -e haskell stack-test         # Test all packages
pixi run -e haskell haskell-test-all   # Test all Haskell packages
pixi run -e haskell hydra-test         # Test core package
pixi run -e haskell ext-test           # Test extensions
----

===== Interactive Development
[source,bash]
----
pixi run -e haskell stack-ghci         # Multi-package GHCi
pixi run -e haskell ghci-all           # All packages GHCi
pixi run -e haskell hydra-ghci         # Core package GHCi
pixi run -e haskell ext-ghci           # Extensions GHCi
pixi run -e haskell ghci-interactive   # Interactive GHCi
pixi run -e haskell ghci-all-fixed     # Fixed GHCi variant
pixi run -e haskell ghci-system        # System GHC GHCi
pixi run -e haskell ghci-minimal       # Minimal conda interference
----

===== Code Generation
[source,bash]
----
pixi run -e haskell generate-java      # Generate Java code
pixi run -e haskell generate-haskell   # Generate Haskell code
----

===== Data and Testing
[source,bash]
----
pixi run -e haskell check-data         # Check source data
pixi run -e haskell check-graphson     # Check GraphSON files
pixi run -e haskell check-copilot-data # Check copilot data
pixi run -e haskell check-sales-data   # Check sales data
pixi run -e haskell run-copilot-graphson    # Generate copilot GraphSON
pixi run -e haskell run-example-graphson    # Generate example GraphSON
pixi run -e haskell graphson-help           # GraphSON function help
----

===== Exploration and Debugging
[source,bash]
----
pixi run -e haskell haskell-modules    # List modules
pixi run -e haskell haskell-functions  # Find functions
----

===== Cleanup
[source,bash]
----
pixi run -e haskell stack-clean                # Clean Stack builds
pixi run -e haskell haskell-clean-all          # Clean all Haskell builds
pixi run -e haskell clear-stack-cache-haskell  # Clear core cache
pixi run -e haskell clear-stack-cache-ext      # Clear extensions cache
pixi run -e haskell clear-stack-cache-all      # Clear all caches
----

==== Development Workflow Recommendations

1. **Initial Setup**: `pixi run validate` → `pixi run -e haskell haskell-setup` → `pixi run build-all`
2. **Daily Development**: `pixi run -e haskell stack-ghci` for interactive development
3. **Testing Changes**: `pixi run -e haskell stack-test` → `pixi run build-all`
4. **Code Generation**: `pixi run -e haskell generate-haskell` → `pixi run -e haskell generate-java`
5. **Troubleshooting**: `pixi run clean` → `pixi run -e haskell clear-stack-cache-all` → rebuild

==== Debugging Build Issues

. Check dependency tiers - ensure no circular dependencies
. Verify all primitive functions are implemented
. Check that generated code is up to date
. Review error logs for missing imports or type mismatches

[source,bash]
----
# Clean and rebuild when issues arise
pixi run clean
pixi run build-all

# For Haskell-specific issues
pixi run -e haskell stack-clean
pixi run -e haskell clear-stack-cache-all
pixi run -e haskell stack-build

# For Java-specific issues
pixi run -e java gradle-clean
pixi run -e java gradle-build
----

==== Contributing Guidelines

. Follow the established dependency tier structure
. Write comprehensive tests for new features
. Update documentation for any API changes
. Ensure all language implementations maintain parity
. Follow the release process for version bumps
