== Welcome to Hydra Documentation

This is the documentation hub for the Hydra project, a multi-language functional programming toolkit with modern pixi-based build system. In Josh Shinavier's words: "In Hydra, programs are graphs, and graphs are programs."

== Quick Start

Get started quickly with these essential pixi tasks:

[source,bash]
----
# Clone and setup
git clone https://github.com/CategoricalData/hydra
cd hydra
pixi install

# Validate installation
pixi run validate

# Build all components
pixi run build-all

# Setup Haskell development (complete implementation)
pixi run -e haskell haskell-setup
----

== Documentation Structure

The documentation follows a modular structure:

=== Main Guides
* `developer-guide.adoc` - Core development guide
* `implementor-guide.adoc` - Language implementation guide
* `operator-guide.adoc` - Data transformation operator guide
* `index.adoc` - This documentation index

=== Section Files (`docs/sects/`)
* **Developer sections**: `dependency-tiers.adoc`, `code-generation.adoc`, `release-management.adoc`
* **Implementor sections**: `implementor-fundamentals.adoc`, `implementor-steps.adoc`, `implementor-guidelines.adoc`
* **Operator sections**: `operator-fundamentals.adoc`, `transformation-examples.adoc`
* **Haskell sections**: `haskell-setup.adoc`, `pixi-haskell-tasks.adoc`, `pixi-task-status.adoc`

This modular approach allows for:
* **Focused content**: Each section covers a specific topic area
* **Easy maintenance**: Sections can be updated independently
* **Reusability**: Sections can be referenced from multiple guides
* **Better organization**: Related content is grouped logically
