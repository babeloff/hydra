This document provides a quick reference for all available pixi tasks for Haskell development in the Hydra project using *ghcup* for toolchain management.

[NOTE]
====
*NEW APPROACH*: Tasks now use ghcup-managed GHC and Stack, avoiding previous conda-forge Stack compatibility issues.
====

== Prerequisites

[source,bash]
----
# Install system dependencies (run once)
./install-haskell-deps.sh

# Set up ghcup-managed GHC and Stack with conda integration (run once)
pixi run -e haskell ./setup-ghcup-with-conda.sh

# Or run the setup tasks individually:
pixi run -e haskell haskell-setup
----

=== Available Modules in GHCi

When using multi-package GHCi, you can load modules from both packages:

[source,haskell]
----
-- Core Hydra modules (from hydra-haskell)

:l Hydra.Core.Type

-- Extension modules (from hydra-ext)
:l Hydra.Ext.Java.Language
:l Hydra.Ext.Python.Language
:l Hydra.Ext.Demos.GenPG.Demo

-- Browse available functions

:type someFunction
:reload

=== Direct Stack Commands (Now Recommended)

With ghcup setup, direct Stack usage now works reliably with proper environment variables:

[source,bash]
----
# From project root (multi-package) - [+] Now works
stack ghci --system-ghc    # [+] Uses ghcup-managed GHC
stack build --system-ghc   # [+] Uses ghcup-managed GHC

# From individual package directories - [+] Now works
cd hydra-haskell && stack ghci --system-ghc  # [+] Works with system GHC
cd hydra-ext && stack ghci --system-ghc      # [+] Works with system GHC

# Remember to set environment variables for conda integration:
export LD_LIBRARY_PATH="$CONDA_PREFIX/lib:$LD_LIBRARY_PATH"
export GHCUP_INSTALL_BASE_PREFIX="$CONDA_PREFIX"
----
